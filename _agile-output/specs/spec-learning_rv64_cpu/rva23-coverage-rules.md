# RVA23 覆盖映射规则

- 依据官方 RVA23 Profile v1.0。`RVA23S64` 对必选用户级要求的继承关系必须显式记录。
- 对每项官方必选要求建立一个带稳定键的行，键包含 profile、规范版本和精确要求 ID。扩展名及其规范行为要求均纳入清单。
- Kunminghu 与 Heliodor 各自有独立状态、实现位置或明确的范围/不可用决定、理由、覆盖子案例和证据 ID。
- 状态值：`not-studied`（在范围内但尚未调查）、`partially-studied`、`studied-unverified`、`evidence-observed`（本项目观察到证据，不是认证）、`not-present`（有检查证据支持不存在）、`out-of-scope`（学习者明确决定并说明理由）。
- 不可用证据不等于实现不存在。必选、可选、建议、上游声明和本项目观察分别标识。局部 RTL、单个测试或上游声明不证明完整符合。
- 最终汇总按 profile 和实现统计状态，列出未解决项；它是学习证据映射，不是符合性认证。
