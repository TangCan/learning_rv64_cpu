# 学习路线

| 阶段 | 主题 | 可观察的完成信号 |
| --- | --- | --- |
| 0 | 来源与环境：仓库结构、快照、硬件描述语言与工具链入口 | 记录两个来源的分支和 commit；定位核心代码和现有测试入口；回答环境阶段自检并记录运行阻塞。 |
| 1 | 指令路径：从 `ADD` 起步，后续再选择控制流和访存单元 | 完成 ADD 对照试点；解释架构结果，定位两边译码、执行和写回路径并引用证据。 |
| 2 | 乱序处理：重命名、发射、执行、提交、分支恢复（候选，对应史诗 2） | 复盘 `ready` 明确授权史诗 2 后，追踪一组依赖指令和一次冲刷/恢复路径，区分两边对应结构。 |
| 3 | 内存与特权：LSU、缓存、原子操作、异常、MMU 和特权级（候选，对应史诗 3） | 复盘 `ready` 明确授权史诗 3 后，追踪一次访存和一次异常或地址转换路径，说明验证边界。 |
| 4 | RVA23 扩展：标量、向量 V、虚拟化 H 和其他必选项（候选，对应史诗 4） | 复盘 `ready` 明确授权史诗 4 后，将所有必选项映射到两边实现、状态和证据；未验证或范围外项要有理由。 |

每阶段均要求记录规范行为、两边源码路径、验证依据和自检答案，并至少完成一项带证据的解释、源码定位或测试/仿真检查。阶段按先修关系推进。阶段 2–4 是候选范围；仅当 ADD 复盘给出的 `ready` 列明对应史诗时才启动，范围、单元和节奏以复盘确认为准。
