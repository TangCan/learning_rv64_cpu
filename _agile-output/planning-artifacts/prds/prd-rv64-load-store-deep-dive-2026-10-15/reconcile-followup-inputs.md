# PRD 与 follow-up 输入对照

- **未发现遗漏的核心意图或重大冲突。** PRD 保留了固定双核快照、LD/SD/共同 fault、证据分级、未知项标记、学习日志与知识单元分工，以及不改 RTL、不宣称 RVA23 符合性的边界。
- **勘察材料内部的 SD 门槛差异已妥善处理。** PRD 要求追踪可证实路径，并允许把源码无法确认的可见性边界标为未知，符合 Spec 的证据边界。
- **仅有轻微措辞风险：** FR-3 写“从译码/发射……到退休”，容易被读成所有阶段必须观测。其验收结果已限定为“来源支持的路径”，且 PRD 允许静态证据与未验证状态，因此不构成实质冲突；若要更严谨，可改成“追踪有证据支持的阶段，未观察阶段标为未知”。
