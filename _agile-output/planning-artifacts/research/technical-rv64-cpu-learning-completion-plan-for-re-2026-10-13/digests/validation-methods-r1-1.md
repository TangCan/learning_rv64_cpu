# Validation-methods research digest, round 1

Accessed: 2026-10-13. This digest is based only on pages retrieved in this research run.

- Claim: RISC-V Architectural Certification Tests (ACTs) are assembly tests intended to help check conformance to specifications, but the project explicitly says they are not verification tests and additional processor verification is needed. Source: https://github.com/riscv/riscv-arch-test ; publisher: RISC-V International `riscv-arch-test`; pub date: not stated in retrieved README; accessed 2026-10-13; confidence: high; class: validation-scope.
- Claim: ACT4 generates self-checking ELFs using a UDB DUT configuration, macros, linker script, and Sail-derived expected results; the user must run the ELFs on the DUT with their own testbench. Source: https://github.com/riscv/riscv-arch-test ; publisher: RISC-V International `riscv-arch-test`; pub date: not stated; accessed 2026-10-13; confidence: high; class: tooling-compatibility.
- Claim: The ACT4 certification test plan lists an RVA23S64 test suite and coverage plan for mandatory and selected optional extensions, but its assumptions and scope must be checked against the profile CRD. Source: https://github.com/riscv/riscv-arch-test/blob/act4/docs/ctp/src/profiles.adoc ; publisher: RISC-V International `riscv-arch-test`; pub date: branch `act4`, date not stated; accessed 2026-10-13; confidence: medium; class: test-coverage.
- Claim: The certification test plan describes profiles and suites; certification targets normative profile rules and does not cover all microarchitecture-aware verification obligations. Source: https://github.com/riscv/riscv-arch-test/blob/act4/docs/ctp/src/intro.adoc ; publisher: RISC-V International `riscv-arch-test`; pub date: branch `act4`, date not stated; accessed 2026-10-13; confidence: high; class: validation-scope.
- Claim: The RISC-V Sail model is an executable formal ISA specification used as a reference model and supports multiple forms of tool generation; being an oracle does not itself validate a hardware implementation. Source: https://github.com/riscv/sail-riscv ; publisher: REMS / Sail RISC-V project; pub date: not stated in retrieved page; accessed 2026-10-13; confidence: medium; class: validation-method.

Leads/open: inspect exact ACT4 coverage entries and test source for these five extensions; determine whether a matching DUT configuration and runnable simulator/harness exist for either study target. The public README establishes the harness shape but not the targets' current integration status.
- Claim: ACT4 has an open issue adding Sscofpmf tests, labeled as needing Sail support and marked needs-review in the retrieved issue listing; therefore the suite cannot be assumed to provide runnable Sscofpmf coverage today. Source: https://github.com/riscv/riscv-arch-test/issues/2181 ; publisher: RISC-V International `riscv-arch-test`; opened 2026-08-24, updated 2026-10-11; accessed 2026-10-13; confidence: medium; class: test-coverage.
- Claim: A 2026 ACT4 critical review report describes defects and untested code around Ssstateen suite generators, including wrong coverpoint labels and unguarded mode/extension paths; use ACT output as supplemental evidence only and inspect test generator quality. Source: https://github.com/riscv/riscv-arch-test/issues/2146 ; publisher: RISC-V International `riscv-arch-test`; published 2026-09 (issue review, retrieved page); accessed 2026-10-13; confidence: medium; class: test-quality.
- Claim: ACT4 configuration requires an explicit UDB DUT configuration plus Sail config, test macros and linker script; Sail compatibility/configuration mismatches have been reported as an integration friction. Source: https://github.com/riscv/riscv-arch-test/discussions/1253 ; publisher: RISC-V International `riscv-arch-test`; 2026-04-14; accessed 2026-10-13; confidence: medium; class: tooling-compatibility.
