## Search limitations and implications

- Static names/paths do not prove a profile requirement is active in the Kunminghu configuration or correctly implemented. Resolve wrapper, feature configuration and build target before test design.

- Ssnpm requires matching profile terminology and behavioral cases; upstream uses aliases/related labels (`Supm`, `PMM`, `Ssnpm`) that must be reconciled against the ratified pointer-masking spec.
- The strongest open question is Heliodor Ssstateen: determine whether registers are intentionally absent; if so, record a profile feature gap rather than inventing source evidence or changing upstream RTL.
