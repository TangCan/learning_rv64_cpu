# Product Brief: RV64 CPU 双项目学习计划

## Executive Summary

本项目通过对照阅读香山 Kunminghu V2 和 Heliodor，系统学习 RV64 CPU 架构与微架构。每次围绕同一指令或功能，追踪两边的实现路径，并用笔记和小实验检验理解。

## The Problem

[ASSUMPTION] 单看 ISA 规范或单个处理器实现，不容易把指令行为、流水线数据流和微架构取舍联系起来。发起人希望通过同功能的双实现对照，建立从架构行为到硬件描述代码的连贯理解。

## The Solution

以香山 Kunminghu V2 和 Heliodor 为参照，按功能追踪设计入口、数据流、状态变化和验证方式，记录共同的架构行为及各自的实现取舍。

[ASSUMPTION] 主要交付物是结构化学习笔记和小型实验；本项目暂不以独立实现完整 CPU 为目标。工具链、仿真方式和实验范围将在 PRD 阶段确定。

## Who This Serves

主要学习者：Richard。项目按个人能力提升规划；先验知识、目标深度以及是否面向其他读者仍待确认。

## Success Criteria

[ASSUMPTION] 每个阶段结束时，学习者能解释目标功能的 ISA 行为，指出两边实现的关键模块，并用测试或小实验验证理解。笔记是否公开、学习深度和完成时间待确认。

## Scope

学习路线暂定从整数指令开始，逐步覆盖控制流、访存、乱序执行、虚拟内存、向量、虚拟化和多核；各阶段的先后与深度将在 PRD 阶段确定。

暂不包括独立实现完整 CPU、流片或取得官方 RVA23 认证。是否覆盖 SoC 组件待确认。

## Vision

长期希望能独立阅读高性能 RV64 处理器实现，在架构行为、微架构组织和具体代码之间建立联系，并比较不同设计的取舍。项目是否发展为公开教程或后续 CPU 实现待定。
