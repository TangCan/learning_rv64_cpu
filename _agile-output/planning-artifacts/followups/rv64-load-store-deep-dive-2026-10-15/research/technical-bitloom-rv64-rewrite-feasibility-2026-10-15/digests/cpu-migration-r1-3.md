# Kunminghu and Heliodor migration characteristics — round 1

Accessed 2026-10-15. Upstream documentation and repos only. Inferences are labeled.

- Kunminghu target: OpenXiangShan/XiangShan branch `kunminghu-v3`; official README says the branch is actively evolving and recommends V2 for research/downstream use when stability matters. Source language and flow are Scala/Chisel (README tree shows `src/main/scala` and `make verilog`; Verilator C++ emulation). Source: https://github.com/OpenXiangShan/XiangShan/tree/kunminghu-v3 (OpenXiangShan; README last updated 2026-06-30; accessed 2026-10-15; high).
- Official Kunminghu V2R2 overview documents RV64/RVV 1.0, MMU and Sv39/48-bit VA, L1/L2 caches and TLBs, TileLink/partial CHI, AIA/IMSIC, timers, debug and HPM. The docs identify it as a general purpose server/high-performance embedded design. Source: https://docs.xiangshan.cc/projects/user-guide/en/kunminghu-v3/introduction/ (XiangShan Team / Beijing Institute of Open Source Chip; copyright 2024–25; accessed 2026-10-15; high).
- Heliodor target: `dalance/heliodor`, a Veryl source tree. Its README describes an RV64 RVA23-capable 2-wide OoO core plus RVV, hypervisor, Sv39, MESI L2, peripherals and 1/2/4/8-hart SMP; includes ACT4/Sail, directed and Linux boot tests. Source: https://github.com/dalance/heliodor (dalance/GitHub; accessed 2026-10-15; high for repository's stated feature and validation scope).
- **Migration inference:** to rewrite either design in Bitloom requires reimplementing RTL source and porting or rebuilding each core's simulation, compliance, system and build infrastructure. Kunminghu may have a FIRRTL intermediate path into Bitloom, but Bitloom's own docs say it does not parse Chisel Scala, so `.fir` import is not a source rewrite. Heliodor is Veryl and no direct Veryl source importer surfaced in Bitloom docs. Full equivalence and system bring-up remain substantial new verification work.

Caveat: Kunminghu specifics above refer to the official V2R2 overview while source branch is V3; do not assume every V2R2 IP is available/stable on V3. For Heliodor, complexity and verification claims are publisher self-reports; this pass did not independently reproduce them.
